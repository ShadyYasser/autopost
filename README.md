# autopost — ناشر تلقائي متعدد العلامات

ناشر فيديوهات عربي يعمل مجانًا على GitHub Actions. يأخذ الفيديوهات من Google Drive وينشرها على
فيسبوك وإنستغرام (مباشرة عبر Graph API) وتيك توك ويوتيوب شورتس (عبر Buffer) في مواعيد محسوبة،
ويرسل لك التنبيهات والملخص اليومي على تيليجرام.

- كل الإعدادات في `config/`؛ **إضافة علامة جديدة = إضافة ملف إعداد فقط** (بدون تعديل كود).
- مصدر المحتوى الوحيد هو Google Drive (عبر Service Account).
- لا يُحفظ أي توكن أو سر داخل المستودع؛ كلها في GitHub Secrets ويُشار إليها بالاسم فقط.
- الحالة (ما نُشر ومتى) في `state/state.db` ويحفظها البوت في المستودع بعد كل تشغيل.

قبل التشغيل الفعلي راجع **[قائمة الإطلاق](docs/go-live.md)**.

## 1. الأسرار المطلوبة (GitHub Secrets)

المكان: المستودع ← **Settings** ← **Secrets and variables** ← **Actions** ← **New repository secret**.
اكتب الاسم **بالضبط** كما هو هنا (حروف كبيرة).

### أسرار أساسية (مطلوبة)

| الاسم | ما هو | من أين تحصل عليه |
|---|---|---|
| `GOOGLE_SERVICE_ACCOUNT_JSON` | ملف JSON الخاص بحساب الخدمة (الصق محتوى الملف كاملًا) | [Google Cloud Console](https://console.cloud.google.com) ← أنشئ مشروعًا ← فعّل **Google Drive API** و**Google Sheets API** ← IAM & Admin ← **Service Accounts** ← Create ← Keys ← Add key ← JSON. ثم شارك مجلدات Drive (قارئ) وشيت تكوين (**محرر**، لأن البوت يكتب تاريخ النشر في العمود C) مع بريد حساب الخدمة (`…@….iam.gserviceaccount.com`). |
| `TELEGRAM_BOT_TOKEN` | توكن بوت تيليجرام | في تيليجرام: [@BotFather](https://t.me/BotFather) ← `/newbot` ← انسخ التوكن. |
| `TELEGRAM_CHAT_ID` | رقم المحادثة التي تصلها التنبيهات | أرسل أي رسالة للبوت، ثم افتح `https://api.telegram.org/bot<التوكن>/getUpdates` وانسخ `chat.id`. (لمجموعة: أضف البوت إليها؛ الرقم يبدأ بـ `-`). |
| `META_PAGE_TOKEN_TAKWIN` | توكن صفحة فيسبوك «تكوين» (يُستخدم لفيسبوك وإنستغرام المرتبط بها) | [Graph API Explorer](https://developers.facebook.com/tools/explorer/) بتطبيقك ← اختر الصلاحيات أدناه ← Generate Access Token ← من القائمة اختر الصفحة لتحصل على **Page token**. للحصول على توكن لا ينتهي: حوّل توكن المستخدم إلى طويل الأمد ثم اطلب `/me/accounts` به؛ توكن الصفحة الناتج لا ينتهي. تحقق منه في [Access Token Debugger](https://developers.facebook.com/tools/debug/accesstoken/) (Expires: Never). |
| `META_PAGE_TOKEN_KALIMA` | توكن صفحة «كلمة سواء» | بنفس الطريقة، مع صلاحيات إيقاف/إخفاء التعليقات الإضافية أدناه. |
| `BUFFER_API_KEY` | مفتاح Buffer للحساب الأول (تيك توك) | سجّل الدخول إلى حساب Buffer الذي فيه قناتا تيك توك ← [publish.buffer.com/settings/api](https://publish.buffer.com/settings/api) ← أنشئ مفتاحًا. |
| `BUFFER_YOUTUBE_API_KEY` | مفتاح Buffer للحساب الثاني (يوتيوب شورتس) | بنفس الطريقة من حساب Buffer الذي فيه قناتا يوتيوب. |
| `HEALTHCHECK_PING_URL` | رابط المراقبة من healthchecks.io | [healthchecks.io](https://healthchecks.io) ← الفحص `autopost` ← انسخ رابط الـ ping (`https://hc-ping.com/…`). اختياري تقنيًا: إن لم يوجد لا يُرسل ping، والنشر لا يتأثر أبدًا بفشل الـ ping. |

**صلاحيات توكن ميتا** (لكل صفحة):
`pages_show_list`, `pages_read_engagement`, `pages_manage_posts`, `instagram_basic`, `instagram_content_publish`.
**وإضافة لـ «كلمة سواء»** (لأن `comments: off`):
`instagram_manage_comments` (إيقاف تعليقات إنستغرام)، و`pages_read_user_content` + `pages_manage_engagement` (إخفاء تعليقات فيسبوك تلقائيًا).
أمر `check` يتحقق من كل هذه الصلاحيات ومن تاريخ انتهاء التوكن.

### أسرار غير مطلوبة الآن (لميزات معطّلة)

| الاسم | متى تحتاجه |
|---|---|
| `YOUTUBE_CLIENT_ID`, `YOUTUBE_CLIENT_SECRET`, `YOUTUBE_REFRESH_TOKEN_TAKWIN`, `YOUTUBE_REFRESH_TOKEN_KALIMA` | فقط إذا فعّلت `youtube_direct.enabled: true` (رفع مباشر على يوتيوب بعد موافقة Google على تدقيق الـ API). حتى ذلك الحين يرسل البوت الفيديو الطويل على تيليجرام لترفعه يدويًا. |
| `PINTEREST_APP_ID`, `PINTEREST_APP_SECRET`, `PINTEREST_REFRESH_TOKEN_TAKWIN`, `PINTEREST_REFRESH_TOKEN_KALIMA` | فقط عند تفعيل بنترست (`enabled: true` ووضع `board_id` في ملف العلامة). |

`GITHUB_TOKEN` يوفره GitHub تلقائيًا (لرفع الفيديو مؤقتًا إلى Release ‏`media-temp` وحفظ الحالة)؛ لا تضفه.

> **المستودع يجب أن يبقى عامًا (Public)**: Buffer يسحب الفيديو من رابط عام في GitHub Release
> ‏`media-temp`، ويُحذف الملف تلقائيًا بعد النشر (أو بعد 6 ساعات كحد أقصى).

## 2. إضافة محتوى

### تكوين

- **الفيديوهات**: ارفعها في مجلد Drive الخاص بتكوين (مباشرة في المجلد، ليس في مجلد فرعي).
- **الترتيب**: حسب **الرقم في اسم الملف** بترتيب طبيعي: `1.mp4`, `2.mp4`, … `10.mp4`, `455.mp4`.
  الملفات بلا رقم تُنشر في الآخر حسب تاريخ الرفع، ويصلك تنبيه واحد عنها. سمِّ الملفات بأرقام متسلسلة بعد آخر رقم موجود.
- **النصوص**: في الشيت (أول ورقة، أيًا كان اسمها). الصف 1 عناوين:
  - العمود **A** = الكابشن (لفيسبوك وإنستغرام وتيك توك، ووصف يوتيوب).
  - العمود **B** = العنوان (عنوان يوتيوب).
  - العمود **C** = يكتبه البوت (تاريخ آخر استخدام). **لا تكتب فيه.**
- النصوص **مستقلة عن الفيديوهات**: البوت يأخذ الصف التالي بالدور، وعند آخر صف يعود للأول. أضف صفوفًا جديدة في الأسفل متى شئت.
- **المواعيد**: قبل الفجر بـ15 دقيقة (±5)، وقبل المغرب بـ15 دقيقة (±5) — والصلاة موعد نهائي لا يُنشر بعده —
  وموعد ثالث عشوائي إما نهارًا (12:00–16:00) أو ليلًا (بعد المغرب بـ3 ساعات حتى قبل الفجر بـ3 ساعات).

### كلمة سواء

- **قصير**: ارفع في مجلد «القصير» ← يُنشر على فيسبوك (Reel) وإنستغرام وتيك توك ويوتيوب شورتس، 3 مرات يوميًا (حوالي 11:00 و16:00 و21:30، ±60 دقيقة).
- **طويل**: ارفع في مجلد «الطويل» ← فيسبوك (فيديو عادي) + يوتيوب (يصلك على تيليجرام لترفعه يدويًا)، في موعد الليل فقط. موعد الليل ينشر قصيرًا وطويلًا معًا.
- **العنوان = اسم الملف** بدون الامتداد. فسمِّ الملف بالعنوان الذي تريده (مثلًا `ما معنى كلمة سواء؟.mp4`).
  تُحذف بادئة `Copy of ` أو `نسخة من ` تلقائيًا. يُقص العنوان إلى 100 حرف ليوتيوب.
- الترتيب: حسب **تاريخ الرفع** إلى Drive (الأقدم أولًا).
- التعليقات: تُطفأ تلقائيًا في إنستغرام، وتُخفى تلقائيًا في فيسبوك كل 30 دقيقة. تيك توك ويوتيوب من إعدادات الحساب (انظر [docs/comments.md](docs/comments.md)).

### ملاحظات عامة على الفيديو

- أي صيغة مقبولة؛ إن لم يكن الفيديو H.264 + AAC داخل MP4 بمواصفات Reels، يحوّله البوت (مرة واحدة لكل منشور).
  الفيديو الأصغر من 720 بكسل يُكبَّر إلى 720×1280.
- يوتيوب شورتس عبر Buffer للفيديو العمودي أو المربع ومدته 3 دقائق أو أقل؛ غير ذلك يصلك على تيليجرام لترفعه يدويًا.
- **تنبيه نقص المحتوى**: عندما يكفي المتبقي في مجلد 3 أيام أو أقل يصلك تنبيه (مرة يوميًا)، ويظهر ⚠️ في الملخص اليومي.

## 3. التنبيهات والمراقبة

- **تيليجرام**: كل فشل، كل منصة تخطت موعدها النهائي، كل موعد صلاة فات (يُتخطى دون استهلاك الفيديو)، تثبيت ffmpeg بطيء (> 3 دقائق)، ونقص المحتوى.
  وعند فشل Buffer يصلك الفيديو والنص لتنشره يدويًا.
- **الملخص اليومي** بعد 23:30 (بتوقيت القاهرة): ما نُشر في كل موعد ولكل منصة (✅ / ✋ يدوي / ❌ / ⏰)، والمتبقي من الفيديوهات بالأيام، واستهلاك Buffer في آخر 24 ساعة.
  يُرسل فقط عندما يكون `cron_enabled: true`.
- **healthchecks.io**: كل تشغيل فعلي يرسل `/start` في بدايته، ثم الرابط العادي عند النجاح أو `/fail` عند الخطأ.
  إذا توقفت التشغيلات (مثلًا انتهى توكن cron-job.org) يرسل لك healthchecks.io بريدًا.

## 4. التشغيل

- **التشغيل المنتظم**: cron-job.org يستدعي الـ workflow كل 10 دقائق (الإعداد في [docs/cron-job-org.md](docs/cron-job-org.md))،
  وجدول GitHub (`7,37 * * * *`) احتياطي. لا شيء يُنشر إلا إذا كان `cron_enabled: true` في `config/settings.yaml`.
- **تشغيل يدوي**: GitHub ← **Actions** ← **autopost** ← **Run workflow**، واختر `command`:

| الأمر | ماذا يفعل |
|---|---|
| `run` + `dry_run` ✔ | تجربة كاملة بلا نشر ولا كتابة (يمكن تحديد `now` لمحاكاة وقت، و`download` لتنزيل الفيديو وفحصه). |
| `run` بدون `dry_run` | ينشر المواعيد المستحقة الآن (يعمل حتى لو `cron_enabled: false`). |
| `check` | فحص قراءة فقط: تيليجرام، Google، توكنات ميتا وصلاحياتها، قنوات Buffer. |
| `sources` | معاينة الفيديوهات التالية والنصوص من Drive والشيت. |
| `plan` | مواعيد الأيام القادمة. |
| `status` | آخر ما نُشر ومحاولات التسليم. |
| `test-post` | منشور حقيقي واحد الآن (`brand` + `platform`، و`video` = `last` أو اسم ملف). يُسجَّل حتى لا يتكرر في دوره. |
| `meta-info` | ما يقوله فيسبوك/إنستغرام عن منشور معيّن. |
| `validate` | فحص ملفات الإعداد. |

> ملاحظة: كل تعديل على ملف الـ workflow (`.github/workflows/publish.yml`) يجعل GitHub يطلب موافقتك
> مرة واحدة (Approve and run) على أول تشغيل بعده. هذا إجراء أمان من GitHub ولا يمكن إطفاؤه.

## 5. إضافة علامة جديدة

1. انسخ `config/brands/kalima_sawaa.yaml` (أو `takwin.yaml`) إلى `config/brands/<id>.yaml` وغيّر `id` و`name`.
2. ضع معرّفات مجلدات Drive (من رابط المجلد: `drive.google.com/drive/folders/<المعرّف>`) وشاركها مع حساب الخدمة.
3. ضع `page_id` و`ig_user_id` واسم سر التوكن الجديد (مثلًا `META_PAGE_TOKEN_NEWBRAND`) وأضف السر في GitHub.
4. ضع أسماء قنوات Buffer كما تظهر في Buffer (`channel`).
5. اختر المواعيد (`fixed` / `prayer_relative` / `random_window` / `pick_window`) والقوالب.
6. شغّل `validate` ثم `check` ثم `run` مع `dry_run`.

لإيقاف علامة: `enabled: false`. لإيقاف منصة واحدة: `enabled: false` تحت المنصة.

## 6. حل المشاكل

| المشكلة | الحل |
|---|---|
| التشغيل معلّق بـ «Approval required» | Actions ← افتح التشغيل ← **Approve and run** (مرة بعد كل تعديل على الـ workflow). |
| تنبيه «token expired» أو `check` يفشل لميتا | أنشئ توكن صفحة جديدًا بنفس الصلاحيات وحدّث السر. |
| cron-job.org يعطي 401/403 | توكن GitHub (PAT) انتهى أو بلا صلاحية Actions: أنشئ واحدًا جديدًا (docs/cron-job-org.md). |
| وصل فيديو على تيليجرام للنشر اليدوي | Buffer رفض أو تجاوز الحد؛ انشره يدويًا. التفاصيل في رسالة التنبيه. |
| موعد صلاة فات | لم يصل أي تشغيل قبل الصلاة؛ الفيديو لم يُستهلك وسيُنشر في الموعد التالي. |

## للمطورين

```bash
pip install -r requirements-dev.txt -e .
python -m autopost validate --check-secrets
python -m autopost plan --days 3
python -m autopost run --dry-run --now 2026-10-27T17:37
python -m pytest
```
