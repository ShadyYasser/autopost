# autopost — ناشر تلقائي متعدد العلامات

ناشر فيديوهات تلقائي يعمل على GitHub Actions ويُدار بالكامل من ملفات الإعداد في مجلد `config/`.

> ⚠️ المشروع قيد البناء على مراحل. الدليل الكامل بالعربية (الأسرار المطلوبة بأسمائها الدقيقة ومن أين تحصل على كل منها، وطريقة إضافة محتوى لكل علامة) سيُكتب في المرحلة الأخيرة.

## الحالة الحالية (المرحلة 1)

- ملفات الإعداد: `config/settings.yaml` و`config/brands/*.yaml` (إضافة علامة جديدة = إضافة ملف).
- الجدولة: مواعيد ثابتة مع تذبذب عشوائي، ومواعيد مرتبطة بأوقات الصلاة (محسوبة دون إنترنت)، ونوافذ عشوائية.
- التشغيل التجريبي (dry run) فقط؛ النشر الفعلي يأتي في المرحلتين 3 و4.

## أوامر مفيدة

```bash
pip install -r requirements-dev.txt
export PYTHONPATH=src
python -m autopost validate --check-secrets   # فحص الإعداد والأسرار
python -m autopost plan --days 3              # معاينة مواعيد النشر
python -m autopost run --dry-run              # تشغيل تجريبي (لا ينشر ولا يكتب شيئًا)
python -m autopost run --dry-run --now 2026-10-27T17:37   # محاكاة وقت معيّن
python -m pytest
```
